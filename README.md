# Немново Тур — питч-демо (v2)

Концепция редизайна сайта туристической компании «Немново Тур» (Гродно).
Один файл `index.html` со встроенными CSS и JS, без сборщиков и внешних библиотек.
Фотографии — в `assets/` (с действующего сайта, сжаты).

Арт-дирекция — редакционный travel-сайт (Kinfolk / Patagonia / National Geographic):
тёмная кинематографичная палитра, сериф Lora + гротеск Manrope, волосяные линии,
крупная типографика. qwencloud.com — только ориентир по качеству исполнения,
композиция не копируется.

## Как открыть

Просто откройте `index.html` в браузере — всё работает без сервера.

Локальный сервер (рекомендуется, корректнее грузятся шрифты и фото):

```bash
python -m http.server 8790
```

и затем `http://127.0.0.1:8790/index.html` из этой папки.

## Что внутри

1. Первый экран — полноэкранное фото, координаты, серифный заголовок,
   две ссылки и полоса цифр (6–38 км · от 55 руб. · от 6 человек) + телефон.
2. Индекс маршрутов — тёмный список-расписание, 10 маршрутов,
   при наведении — превью-фото следует за курсором (на мобильном отключено).
3. Манифест — тёмная секция с цитатой.
4. Что входит — светлая асимметрия: цифра 85 + 4 пункта.
5. База отдыха — полноширинный блок «Ночлег на Августовском канале».
6. Кадры — горизонтальная галерея с перетаскиванием и кнопками.
7. Цифры — тёмная полоса (16 / 85 / 34 / 8) с анимацией счёта.
8. Как это устроено — четыре шага.
9. Корпоративам — CTA поверх заката.
10. Футер — 4 колонки: маршруты, компания, контакты, реквизиты.

Плюс: модальное окно бронирования (имя, телефон, маршрут, дата, человек,
комментарий) с валидацией и экраном успеха с номером заявки; мобильное меню;
анимации появления; поддержка `prefers-reduced-motion`.

## Что здесь настоящее

- Все 10 маршрутов, длины, время и цены — с действующего сайта и brief.
- Телефоны, email, адрес, УНП, часы работы, расписание сборных — реальные.
- Фотографии — с nemnovotour.by.
- Компании-клиенты — из их списка.

## Что здесь демо

- Форма бронирования ничего не отправляет: проверяет поля и показывает
  экран успеха с номером заявки. В рабочей версии заявка уходит в CRM / менеджеру.
- Логотип-знак и тексты — предложение, а не текущие материалы компании.

## Технические детали

- Адаптив 320 / 390 / 768 / 1024 / 1440, без горизонтального скролла.
- Семантика: один `h1`, видимый `:focus`, aria на модалке и меню.
- Изображения: `alt`, `loading="lazy"` ниже первого экрана, `width/height`.
- CSS-переменные палитры и шкалы; ванильный JS без ошибок в консоли.
